# dsh-peak-chip（DeepSeek 峰谷指示灯）

会话头部一个**圆点**，点开是面板：**本日消耗** 与 **当前余额**。

DeepSeek 按峰谷时段定价，这个插件把"今天花了多少、余额还剩多少"摆在眼前。

显示余额、算今日消耗的同类插件很多。**这个插件和它们最不一样的地方，是「自修复设计」**：
它不假设自己永远算对，而是让**算错的数字自己退回去** —— 不需要你手工清零，也不用重启。

- **判错的充值会自己撤销**：充值识别走「中位数 3 窗滤波 + 正台阶 + 连续窗确认」，
  临时值参与显示但**不落库**；后续窗口的余额证据一旦不支持它，那一笔就自己消失。
  （实测：一次误判的幻影充值，面板那行自己从数字变回了 `—`。）
- **黄灯自己灭**：告警带滞回（进 `≥0.6`、出 `<0.4`，都要求连续 3 窗），水位回落后黄灯自动恢复，
  不用你操作 —— 平台批量结算造成的缺口，落地后也自己回落。
- **错误不跨天遗传**：日边界「零点重锚、零携带」——昨天的错误数字不会带进今天。
- **永久态必须留出口**：连续 3 天红才转灰，而灰的语义是"计费口径已不成立"，
  唯一出口是规则版本变更 —— 它不会静默地永久锁死（这条是被一次真实故障打出来才补上的）。
- **环境变了也不用手工重置**：凭据每次现取（换 API key 不用重启）；缺 3090 桥只降级"充值"按钮，
  面板与记账照常。

> 第三方插件，**非 DeepSeek 官方产品**，与 DeepSeek 官方无隶属关系。
> 面板标题里的鲸鱼标记为 DeepSeek 商标（取自 dsh 自带的 `dsh-web-frontend/dist/favicon.svg`），
> 仅用于指称本插件所读取的服务。

## 安装

从 Release 附件安装（安装器不执行任何构建脚本，本插件是零构建的）：

```sh
dsha-plugin import dsh-peak-chip-4.1.7.tgz
```

装完**重启 dsh web**，并在浏览器里刷新页面。

- 发布包：<https://github.com/sunsun320/dsh-peak-chip/releases/download/v4.1.7/dsh-peak-chip-4.1.7.tgz>

## 它做什么

- **会话头部一个圆点**（指示灯）；
- **面板两个数**：本日消耗 / 当前余额；
- **详单**：本日首次观测余额、当前余额、今日充值识别、本地审计值、"无法审计"差额、误差三档告警。

## 记账口径（一句话）

本地按本机 token 折算的 `L`，与按余额变化推算的 `S = max(0, V + T)`
（`V` = 当日首次余额 − 当前余额）各算一遍；差额按方向拆成
`O = max(0, S − L)`（面板上的"无法审计"：同账号别的客户端花的，正常）与
`E = max(0, L − S)`（误差：本机多算才可疑）。充值靠余额台阶检测
（中位数滤波 + 连续窗确认），判定权只有宿主一处。

详见 [`计费算法说明.md`](计费算法说明.md)。

## 接触面（权限与数据）

- **读**：`$DSH_HOME/.bridge_token`（仅用于走 DSHA 桥）。
- **连**：`api.deepseek.com`（余额查询；凭据用 dsh 设置里已有的 DeepSeek API key，
  插件自己不存 key）；`127.0.0.1:3090`（DSHA 桥，**只用于"充值"按钮**）。
- **写**：只写 settings 命名空间 `dsh-peak-chip`（余额、今日消耗、充值识别结果、调试窗口、自身路径）。
- **不向任何第三方发送数据，无遥测**，不上传对话、不含设备标识。
- **缺桥只降级"充值"按钮**，面板与记账不受影响。
- 原生依赖：无。`lib/client.js` 是预构建单文件 → **安装器不需要执行 build/prepare 脚本**。

## 边界（明确不做）

- 不代替官方计费：所有数字是**本地审计 + 余额变化推算**，误差会显式显示出来；
- 不改模型路由、不改定价参数、不自动充值；
- 电脑端（Windows）未适配：剩下的未知只有两条 —— 那边没有 3090 桥、以及休眠/唤醒行为。

## 环境与验证

- 环境：**DSHA 0.1.5-rc2 / dsh 0.1.5-rc.2**，arm64，Android 手机 WebView（mobile 变体）。
- 自带测试 5 套全绿：`tests/v4-alert` / `v4-client` / `v4-drift` / `v4-preview` / `v4-scenarios`。
- 代码内不写死 `DSH_HOME`（`resolveDshHome()` + `import.meta.url` 自定位），
  并有守卫测试 `tests/v4-drift.test.mjs` 阻止回归。
